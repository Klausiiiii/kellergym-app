# Kellergym Logbuch

Trainings-Tracker fürs Heimgym. Läuft komplett im Browser, Daten bleiben lokal (localStorage) auf dem jeweiligen Gerät.

- Export/Import als JSON im Reiter **Verlauf** (Backup & Umzug zwischen Geräten)
- CSV-Export für Excel
- Installierbar als App (PWA), funktioniert offline

**Keine Trainingsdaten committen** – Exporte gehören nicht ins Repo.
